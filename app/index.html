Synthetic Population Clusters

What is this?

'Synthetic users' are a hot topic in user research - conducting research byasking an LLM to respond to questions 'as though' it is a user with particular characteristics. This approach is very hard to validate.

This work explores the hypothesis that a more robust approach could be to supply the LLM with detailed high-quality data about a user group, relying on the LLM only to summarise the most salient aspects of those users.

Use the dropdown above to see demongraphic clusters in UK local authorities (just London Boroughs for now) based on age, employement status, ethnicity, eduction and income. For each cluster the LLM is given further background information and comparative data to support writing a short description of the cluster. It also generates a profile image.

It uses ChatGPT to write the description and title of each cluster and generate a portrait image.

The data comes from the UK Household Longitudinal Study (UKHLS).

Annonymnity is preserved by using Sipher, which takes the UKHLS data and creates a synthetic population of 52 million people.

Sipher's approach is to randomise the locations of respondents in a way that keeps overall statistical validity while making it very hard to identify any individual respondents.

Custom code uses 'k-means clustering' to group the respondents into clusters.
